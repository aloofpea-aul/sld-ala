# Single Line Diagram - สถานีไฟฟ้าอ่าวลึก

โปรแกรมแสดงผังซิงเกิ้ลไลน์ไดอะแกรม โดยมี **สถานีไฟฟ้าอ่าวลึก** เป็นจุดศูนย์กลาง
แตกออกเป็น 7 วงจรจ่ายไฟ (ALA01, ALA02, ALA03, ALA05, ALA06, ALA07, ALA09)
คลิกที่เส้นวงจรแต่ละสีเพื่อดูรายการอุปกรณ์ทั้งหมดในวงจรนั้น (WS/WF/WR/MR/WC/SW)
หรือค้นหาด้วยรหัสอุปกรณ์ / ชื่อสถานที่ได้จากช่องค้นหาด้านบน

ข้อมูลอุปกรณ์ถอดออกจากไฟล์แบบ AutoCAD ที่แนบมา (A0-ALA 15 พ.ค. 68) รวม **407 รายการ**
เนื่องจากตัวหนังสือในแบบบางจุดมีขนาดเล็กมาก จึงอาจมีบางรายการที่ชื่อสถานที่/ค่าพิกัดอ่านคลาดเคลื่อน
หรือตกหล่นไปบ้าง — แนะนำให้ตรวจสอบและแก้ไขเพิ่มเติมได้ทาง Google Sheet (ดูขั้นตอนด้านล่าง)

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บหลัก นำไปวางบน GitHub Pages ได้ทันที (มีข้อมูลฝังไว้ในตัวแล้ว ใช้งานได้แม้ไม่ต่อ Google Sheet) |
| `devices.csv` | รายการอุปกรณ์ทั้งหมด 407 ตัว สำหรับ import เข้า Google Sheet |
| `feeders.csv` | ข้อมูลวงจรทั้ง 7 วงจร (สี, ชื่อ, จุดเชื่อมโยง) สำหรับ import เข้า Google Sheet |
| `Code.gs` | Apps Script backend สำหรับดึงข้อมูลจาก Google Sheet มาเป็น JSON |

## วิธี Deploy บน GitHub Pages (ใช้งานได้เลย ไม่ต้องมี Google Sheet)

1. สร้าง repository ใหม่บน GitHub (หรือใช้ repo เดิม)
2. อัปโหลดไฟล์ `index.html` เข้าไปใน repo (ผ่านหน้าเว็บ GitHub “Add file > Upload files”)
3. ไปที่ Settings > Pages > เลือก branch ที่ใช้งาน แล้วกด Save
4. รอสักครู่ จะได้ลิงก์เว็บไซต์ เช่น `https://<username>.github.io/<repo>/`

ขั้นตอนนี้เพียงพอสำหรับใช้งานได้ทันที เพราะข้อมูลทั้งหมดฝังอยู่ใน `index.html` แล้ว

## วิธีต่อกับ Google Sheet + Apps Script (เพื่อแก้ไขข้อมูลได้ง่ายในอนาคต)

ถ้าต้องการแก้ไข/เพิ่มเติมรายการอุปกรณ์ทีหลังโดยไม่ต้องแก้โค้ด ให้ทำตามนี้:

1. สร้าง Google Sheet ใหม่ 1 ไฟล์ ตั้งชื่อ เช่น "SLD อ่าวลึก - ข้อมูลอุปกรณ์"
2. สร้างชีตชื่อ **Devices** แล้ว import ไฟล์ `devices.csv` เข้าไป (File > Import > Upload)
3. สร้างชีตชื่อ **Feeders** แล้ว import ไฟล์ `feeders.csv` เข้าไป
4. เปิด Extensions > Apps Script วางโค้ดจากไฟล์ `Code.gs` ทับของเดิม
5. กด Deploy > New deployment > เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. คัดลอก URL ของ Web app ที่ได้ (ลงท้ายด้วย `/exec`)
7. เปิดไฟล์ `index.html` แก้บรรทัด:
   ```js
   const GAS_WEB_APP_URL = "";
   ```
   ใส่ URL ที่คัดลอกมาแทน แล้วอัปโหลดไฟล์ `index.html` ที่แก้แล้วขึ้น GitHub Pages ใหม่อีกครั้ง

หลังจากนี้ทุกครั้งที่แก้ไขข้อมูลใน Sheet (เพิ่ม/ลบ/แก้ชื่อสถานที่) หน้าเว็บจะดึงข้อมูลล่าสุดมาแสดงอัตโนมัติ
โดยไม่ต้องแก้โค้ดหรืออัปโหลดไฟล์ใหม่อีก

## โครงสร้างข้อมูลใน Sheet "Devices"

| Feeder | DeviceID | Type | Rating | Description |
|---|---|---|---|---|
| ALA01 | ALA01WS-101 | WS | | เซอร์กิตเบรกเกอร์ต้นทาง (สถานี) |
| ALA01 | ALA01WF-107 | WF | 6K | บ.ถ้ำยวนทอง |

- **Feeder**: รหัสวงจร ต้องตรงกับคอลัมน์ FeederID ในชีต Feeders
- **Type**: WS (สวิตช์), WF (ฟิวส์คัตเอาต์), WR/MR (รีโคลสเซอร์), WC (คาปาซิเตอร์แบงค์), SW (สวิตช์อื่นๆ)
- **Rating**: ขนาดฟิวส์/พิกัด เช่น 6K, 10K, 15K
- **Description**: จุดติดตั้ง/ชื่อผู้ใช้ไฟ — แก้ไขหรือเพิ่มเติมได้อิสระในนี้

## จุดที่ควรตรวจสอบเพิ่มเติม

- ชื่อสถานที่ภาษาไทยหลายจุดในแบบต้นฉบับมีขนาดเล็กมาก การถอดข้อมูลอาจคลาดเคลื่อนในบางจุด
- ลำดับอุปกรณ์ที่แสดงในตารางเรียงตามที่พบในแบบ ไม่ได้สะท้อนตำแหน่งจริงบนเสาไฟฟ้า 100%
- อุปกรณ์บางจุดที่ทับซ้อนกับเส้นวงจรอื่นในแบบต้นฉบับอาจตกหล่น แนะนำให้ผู้ที่ทำงานภาคสนามช่วยตรวจทานอีกครั้ง
