# Single Line Diagram - สถานีไฟฟ้าอ่าวลึก

โปรแกรมแสดงผังซิงเกิ้ลไลน์ไดอะแกรม โดยมี **สถานีไฟฟ้าอ่าวลึก** เป็นจุดศูนย์กลาง
แตกออกเป็น 7 วงจรจ่ายไฟ (ALA01, ALA02, ALA03, ALA05, ALA06, ALA07, ALA09)

## อัปเดตล่าสุด: รวมฐานข้อมูล GIS จริงเข้ากับระบบแล้ว

ข้อมูลอุปกรณ์ตอนนี้มาจาก **2 แหล่งรวมกัน**:
1. ข้อมูลที่ถอดจากแบบ AutoCAD (การอ่านด้วยตา อาจคลาดเคลื่อนได้บ้าง)
2. **ฐานข้อมูล GIS จริงของ PEA** (ไฟล์ SWXY, CBXY, RecloserXY ที่อัปโหลดมา) ซึ่งมีรหัสอุปกรณ์,
   ขนาดพิกัด (Amps/K), ตำแหน่ง GPS จริง, และชื่อจุดติดตั้งจริงจากระบบ

ผลการเทียบข้อมูล: อุปกรณ์ที่ถอดจากแบบ **362 จาก 407 ตัว (89%) ตรงกับฐานข้อมูล GIS** ยืนยันว่าการถอดข้อมูล
จากแบบมีความแม่นยำสูง ส่วนที่เหลือ (ส่วนใหญ่คือคาปาซิเตอร์แบงค์ WC ซึ่งไม่อยู่ในฐานข้อมูล GIS ชุดนี้)
ยังคงเก็บไว้ตามเดิมและมีป้าย **"🔍ต้องตรวจสอบ"** กำกับไว้ในหน้าเว็บ

ฐานข้อมูล GIS ยังพบอุปกรณ์อีก **236 ตัว ที่ไม่เคยปรากฏในแบบที่ถอดไว้เดิม** — ได้เพิ่มเข้าระบบทั้งหมดแล้ว
ทำให้ฐานข้อมูลตอนนี้มี **รวม 632 อุปกรณ์** (จากเดิม 407) และ **587 ตัวมีพิกัด GPS จริง**

## ฟีเจอร์ใหม่: แผนที่จริง (GPS)

กดปุ่ม **🗺 แผนที่จริง (GPS)** มุมขวาบน เพื่อสลับจากผังวงจร (schematic) ไปเป็น**แผนที่จริง**
แสดงตำแหน่งอุปกรณ์ทุกตัวตามพิกัด GPS จริงบนแผนที่ (ใช้ OpenStreetMap) สีตามวงจรเดิม
คลิกจุดใดก็ได้เพื่อดูรายละเอียดในแถบด้านขวา — ใช้เปรียบเทียบตำแหน่งจริงกับผังวงจรได้โดยตรง
**ต้องใช้อินเทอร์เน็ต** เพื่อโหลดแผนที่ (ใช้ได้ปกติเมื่อ deploy ขึ้น GitHub Pages)

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บหลัก นำไปวางบน GitHub Pages ได้ทันที (มีข้อมูลฝังไว้ในตัวแล้ว) |
| `devices.csv` | รายการอุปกรณ์ทั้งหมด 632 ตัว (รวม GIS + แบบ) สำหรับ import เข้า Google Sheet |
| `feeders.csv` | ข้อมูลวงจรทั้ง 7 วงจร (สี, ชื่อ, จุดเชื่อมโยง) |
| `Code.gs` | Apps Script backend สำหรับดึง/บันทึกข้อมูลจาก Google Sheet |
| `gis_transformers.csv` | หม้อแปลงจริงทุกลูกในพื้นที่ 7 วงจร (1,816 ตัว) จากฐานข้อมูล GIS — อ้างอิงเพิ่มเติม ไม่ได้ผูกกับผังหลัก |
| `gis_mv_meters.csv` | มิเตอร์แรงกลาง (MV) ในพื้นที่ 7 วงจร (91 ตัว) |
| `gis_mv_meter_accounts.csv` | ข้อมูลบัญชีลูกค้าที่ผูกกับมิเตอร์แรงกลาง |

ไฟล์ `gis_*.csv` เป็นข้อมูลเสริมสำหรับค้นหา/เปรียบเทียบเพิ่มเติม (เช่น เช็คว่าหม้อแปลงจุดไหนมีขนาดเท่าไหร่
ใกล้ปลายวงจรไหน) ยังไม่ได้ผูกเข้ากับ index.html โดยตรง — import เข้า Google Sheet เป็นชีตแยกไว้ดูเพิ่มเติมได้

## วิธี Deploy บน GitHub Pages (ใช้งานได้เลย ไม่ต้องมี Google Sheet)

1. สร้าง repository ใหม่บน GitHub (หรือใช้ repo เดิม)
2. อัปโหลดไฟล์ `index.html` เข้าไปใน repo (ผ่านหน้าเว็บ GitHub "Add file > Upload files")
3. ไปที่ Settings > Pages > เลือก branch ที่ใช้งาน แล้วกด Save
4. รอสักครู่ จะได้ลิงก์เว็บไซต์ เช่น `https://<username>.github.io/<repo>/`

## วิธีต่อกับ Google Sheet + Apps Script (เพื่อแก้ไขข้อมูลได้ง่ายในอนาคต)

1. สร้าง Google Sheet ใหม่ 1 ไฟล์
2. สร้างชีตชื่อ **Devices** แล้ว import ไฟล์ `devices.csv` เข้าไป (มี 8 คอลัมน์ตามตารางด้านบน)
3. สร้างชีตชื่อ **Feeders** แล้ว import ไฟล์ `feeders.csv` เข้าไป
4. (ไม่บังคับ) สร้างชีตเพิ่มเติมสำหรับ `gis_transformers.csv`, `gis_mv_meters.csv` เพื่อเก็บไว้ดูอ้างอิง
5. เปิด Extensions > Apps Script วางโค้ดจากไฟล์ `Code.gs` ทับของเดิม
6. กด Deploy > New deployment > เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
7. คัดลอก URL ของ Web app ที่ได้ (ลงท้ายด้วย `/exec`)
8. เปิดเว็บไซต์ กดปุ่ม **⚙ ตั้งค่า** มุมขวาบน แล้ววาง URL ที่คัดลอกมาลงไป กด OK

หลังจากนี้ทุกครั้งที่เปิดหน้าเว็บ จะดึงข้อมูลล่าสุดจาก Sheet มาแสดงอัตโนมัติ และเมื่อใครใช้ **โหมดแก้ไข**
เพิ่ม/แก้/ลบอุปกรณ์ จะถูกบันทึกลง Sheet ทันที (การตั้งค่า URL ผ่านปุ่ม ⚙ เก็บเฉพาะเบราว์เซอร์เครื่องนั้น —
ถ้าต้องการให้ทุกคนเจอข้อมูลจาก Sheet โดยอัตโนมัติ ให้แก้ `DEFAULT_GAS_URL` ในไฟล์ `index.html` แล้วอัปโหลดใหม่)

## จุดที่ควรตรวจสอบเพิ่มเติม

- อุปกรณ์ที่มีป้าย **"🔍ต้องตรวจสอบ"** (ส่วนใหญ่คือ WC คาปาซิเตอร์แบงค์) ยังไม่พบในฐานข้อมูล GIS ชุดนี้
- ลำดับอุปกรณ์ตามแนวสายเรียงจากเลขรหัสจากน้อยไปมาก (ประมาณตำแหน่งจริง) ไม่ได้ตรวจสอบทุกจุดว่าตรงกับ
  ลำดับสายจริง 100% — ถ้าพบจุดผิดปกติ แก้ไขได้ผ่านโหมดแก้ไขในหน้าเว็บ
- ไฟล์ `gis_transformers.csv` เป็นหม้อแปลงระดับเสาไฟฟ้าจริง (ละเอียดกว่าจุดต่อในผัง SLD) ยังไม่ได้ผูก
  ความสัมพันธ์ 1:1 กับอุปกรณ์ WF แต่ละตัวในผัง (ต้องจับคู่ตามพิกัด GPS ที่ใกล้กันเพิ่มเติมหากต้องการละเอียดขนาดนั้น)
