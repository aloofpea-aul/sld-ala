# Single Line Diagram - สถานีไฟฟ้าอ่าวลึก

โปรแกรมแสดงผังซิงเกิ้ลไลน์ไดอะแกรม โดยมี **สถานีไฟฟ้าอ่าวลึก** เป็นจุดศูนย์กลาง
แตกออกเป็น 7 วงจรจ่ายไฟ (ALA01, ALA02, ALA03, ALA05, ALA06, ALA07, ALA09)

## อัปเดตล่าสุด

### 1. ผังตอนนี้แตกสาขาตามจุดต่อจริง

เดิมผังวาดเป็นเส้นตรงเรียงตามเลขรหัส ตอนนี้เปลี่ยนเป็น **โครงสร้างต้นไม้ (tree) ตามตำแหน่ง GPS จริง**
ของแต่ละอุปกรณ์ — คำนวณเส้นทางที่สั้นที่สุดที่เชื่อมทุกอุปกรณ์เข้าด้วยกัน (Minimum Spanning Tree)
ทำให้จุดที่มีมากกว่า 1 สาขาแตกออกจริงๆ ในผัง ไม่ใช่การกระจายซ้ายขวาแบบสุ่มเหมือนเดิม

### 2. รวมข้อมูลจากทุกไฟล์ที่ให้มาแล้ว

นอกจาก สวิตช์/เบรกเกอร์/รีโคลสเซอร์ (SWXY, CBXY, RecloserXY) ที่ทำไปรอบก่อน ตอนนี้เพิ่ม:
- **หม้อแปลงจริง 1,618 ลูก** (จาก TransXY) — ต่อเข้ากับสวิตช์/ฟิวส์ที่อยู่ใกล้ที่สุดตามพิกัด GPS
- **มิเตอร์แรงกลาง (MV) 91 จุด** (จาก MVMeterXY + MVMeterXYCA) — ลูกค้ารายใหญ่ที่วัดไฟที่แรงดันกลางโดยตรง
- **จำนวนผู้ใช้ไฟต่อหม้อแปลง** (จากไฟล์มิเตอร์หม้อแปลง_กระบี่) แสดงเป็นเลขกำกับที่หม้อแปลงแต่ละลูก
  (เช่น "40-013357 30kVA ⚡24" หมายถึงมีผู้ใช้ไฟต่อพ่วงอยู่ 24 ราย)

รวมทั้งหมดตอนนี้มี **2,341 จุดในระบบ** (632 อุปกรณ์สวิตช์/ฟิวส์/รีโคลสเซอร์ + 1,709 หม้อแปลง/มิเตอร์)

**กดปุ่ม "แสดงหม้อแปลง/มิเตอร์"** มุมขวาบน เพื่อเปิด/ปิดการแสดงชั้นข้อมูลหม้อแปลง-มิเตอร์
(ปิดไว้เป็นค่าเริ่มต้น เพื่อให้ผังดูง่าย เปิดเมื่อต้องการเปรียบเทียบ/ตรวจสอบละเอียด)

### 3. แก้ไขข้อมูลพร้อมระบุสาขาที่ต่อ

โหมดแก้ไขตอนนี้มีช่อง **"ต่อจากอุปกรณ์ใด"** ให้ระบุรหัสอุปกรณ์ต้นทาง เวลาเพิ่ม/แก้ไขอุปกรณ์ใหม่
จะได้ต่อกิ่งถูกจุดในผัง และถ้าลบอุปกรณ์ตรงกลางสาขา ระบบจะเชื่อมอุปกรณ์ปลายสาขาที่เหลือ
ให้ต่อกับสาขาแม่แทนอัตโนมัติ ไม่ทำให้กิ่งขาดหาย

## คอลัมน์ใน devices.csv

| Feeder | DeviceID | Type | Rating | Description | Lat | Lon | Source | ParentID | MeterCount |
|---|---|---|---|---|---|---|---|---|---|

- **Type**: `WB` (เบรกเกอร์ต้นทางที่สถานี), `WS`/`SW` (สวิตช์), `WF` (ฟิวส์คัตเอาต์), `WR`/`MR` (รีโคลสเซอร์),
  `WC` (คาปาซิเตอร์แบงค์), `TRANSFORMER` (หม้อแปลง), `MVMETER` (มิเตอร์แรงกลาง)
- **ParentID**: รหัสอุปกรณ์ต้นทางที่จุดนี้ต่อออกมา (ใช้สร้างผังแบบแตกสาขา) — ถ้าเว้นว่างหมายถึงต่อจากสถานีโดยตรง
- **MeterCount**: จำนวนผู้ใช้ไฟที่ต่อพ่วงกับหม้อแปลงนั้น (มีเฉพาะแถวที่ Type = TRANSFORMER)
- **Source**: `gis` = จากฐานข้อมูล GIS จริง / `manual` = ถอดจากแบบ AutoCAD เท่านั้น ยังไม่พบในฐานข้อมูล GIS

## วิธี Deploy บน GitHub Pages

1. อัปโหลดไฟล์ `index.html` เข้า repo เดิม (ทับไฟล์เก่า) ผ่าน "Add file > Upload files" แล้ว Commit
2. รอ 1-2 นาที เปิดลิงก์เว็บไซต์เดิม — ข้อมูลใหม่จะขึ้นอัตโนมัติ (อาจต้อง Ctrl+F5 ล้างแคช)

## วิธีต่อกับ Google Sheet + Apps Script

1. สร้าง Google Sheet ใหม่ 1 ไฟล์
2. สร้างชีตชื่อ **Devices** แล้ว import ไฟล์ `devices.csv` เข้าไป (มี 10 คอลัมน์ตามตารางด้านบน)
3. สร้างชีตชื่อ **Feeders** แล้ว import ไฟล์ `feeders.csv` เข้าไป
4. เปิด Extensions > Apps Script วางโค้ดจากไฟล์ `Code.gs` ทับของเดิม
5. กด Deploy > New deployment > เลือกประเภท **Web app** (Execute as: Me, Who has access: Anyone)
6. คัดลอก URL ของ Web app (ลงท้ายด้วย `/exec`) แล้วกดปุ่ม **⚙ ตั้งค่า** มุมขวาบนของเว็บ วาง URL แล้วกด OK

## จุดที่ควรตรวจสอบเพิ่มเติม

- อุปกรณ์ที่มีป้าย **"🔍ต้องตรวจสอบ"** ยังไม่พบในฐานข้อมูล GIS ชุดนี้ (ส่วนใหญ่คือคาปาซิเตอร์แบงค์)
- การจับคู่หม้อแปลง/มิเตอร์เข้ากับสวิตช์ที่ใกล้ที่สุด ใช้ระยะทางพิกัด GPS เป็นเกณฑ์ (ไม่เกิน ~1 กม.)
  จุดที่ไกลเกินเกณฑ์ (198 ลูกจาก 1,816) จะไม่ถูกต่อเข้าโครงสร้างต้นไม้ — ยังอยู่ครบใน `gis_transformers.csv`
- โครงสร้างสาขาคำนวณจากระยะทางจริง ไม่ใช่ทิศทางกระแสไฟฟ้าจริง 100% หากพบจุดที่ต่อผิดสาขา
  แก้ไขได้ผ่านโหมดแก้ไข → ช่อง "ต่อจากอุปกรณ์ใด"
