# Single Line Diagram - สถานีไฟฟ้าอ่าวลึก

โปรแกรมแสดงผังซิงเกิ้ลไลน์ไดอะแกรม โดยมี **สถานีไฟฟ้าอ่าวลึก** เป็นจุดศูนย์กลาง
แตกออกเป็น 7 วงจรจ่ายไฟ (ALA01, ALA02, ALA03, ALA05, ALA06, ALA07, ALA09)

## อัปเดตล่าสุด: แก้ 3 ปัญหาที่แจ้งมา

### 1. แก้ขนาดฟิวส์ที่ไม่ตรง (204 ตัว)

พบว่าฐานข้อมูล GIS ใช้ค่า **MAXCONTINU = 50 เป็นค่า default ทั่วไป** สำหรับฟิวส์คัตเอาต์จำนวนมาก
(77 จาก ~200 ตัวในบางส่วนที่ตรวจสอบ) ซึ่ง**ไม่ใช่ขนาดฟิวส์ลิงก์จริงที่ติดตั้งอยู่** — ต่างจากที่วาดไว้ในแบบ
AutoCAD ซึ่งน่าจะสะท้อนขนาดจริงที่ช่างอ่านจากอุปกรณ์มากกว่า

**แก้แล้ว:** เปลี่ยนลำดับความสำคัญ — ใช้ค่าที่อ่านจากแบบ AutoCAD เป็นหลักเสมอเมื่อมีอยู่ (204 ตัวถูกแก้กลับ
เช่น ALA02WF-133 จาก 50K → 15K ตรงกับที่แจ้งมา) ส่วนที่ไม่มีค่าจากแบบ (206 ตัว) ยังคงใช้ค่าประมาณจาก GIS
แต่จะมีป้าย **"ประมาณ"** สีส้มกำกับไว้ในทุกที่ที่แสดงขนาด ให้รู้ทันทีว่าจุดไหนยังไม่ยืนยัน 100%

### 2. แก้แผนที่จริงไม่ขึ้นพิกัด

เจอบั๊กจริงใน Leaflet: ตัวเรนเดอร์ SVG ที่ใช้วาดจุดอุปกรณ์เกิดปัญหาขนาดเป็น 0x0 พิกเซล ทำให้จุดสีถูกวาด
แต่มองไม่เห็นเลย (เฉพาะหมุดสถานีที่ใช้วิธีวาดอื่นถึงจะขึ้น) **แก้แล้ว**โดยเปลี่ยนไปใช้ Canvas แทน SVG
ในการวาดจุด — ตอนนี้เห็นจุดสีของอุปกรณ์ทั้ง 587 ตัวชัดเจน กระจายตามแนวสายจริงในแต่ละวงจร

### 3. ฟีเจอร์ใหม่: ตรวจสอบภาคสนาม (สำหรับงานออกพื้นที่)

กดปุ่ม **"📷 ตรวจสอบภาคสนาม"** มุมขวาบน แล้วเลือกวงจร จะมีไอคอนกล้อง 📷 ที่ทุกแถวอุปกรณ์ — กดแล้ว:
1. เห็นข้อมูลที่ระบบบันทึกไว้ (ขนาด/จุดติดตั้ง) เทียบกับของจริงหน้างาน
2. เลือก **"✅ ตรงกับข้อมูล"** หรือ **"❌ ไม่ตรง"** (ถ้าไม่ตรง ใส่ค่าจริงที่พบ)
3. ใส่ชื่อผู้ตรวจสอบ + หมายเหตุ (ถ้ามี)
4. **ถ่ายรูปอุปกรณ์จริงจากมือถือได้เลย** (ปุ่มเปิดกล้องโดยตรง)
5. กดบันทึก — ข้อมูลในผังอัปเดตทันที พร้อมป้าย "✓ ตรวจแล้ว" หรือ "⚠ แก้ไขแล้ว"

**รูปถ่ายจะถูกอัปโหลดไปเก็บใน Google Drive อัตโนมัติ** (โฟลเดอร์ "SLD-อ่าวลึก-ภาพตรวจสอบภาคสนาม")
พร้อมบันทึกประวัติการตรวจสอบทุกครั้งไว้ในชีต **FieldVerification** แยกต่างหาก (ไม่ทับข้อมูลเก่า เก็บเป็น
ประวัติสะสม ตรวจสอบย้อนหลังได้ว่าใครตรวจ เมื่อไหร่ พบอะไรบ้าง)

**ต้องเชื่อม Google Sheet ก่อนจึงจะอัปโหลดรูปได้จริง** — ถ้ายังไม่เชื่อม ระบบจะบันทึกผลไว้ในเบราว์เซอร์
เครื่องนั้นก่อน (ไม่มีรูป) แล้วมีข้อความเตือนให้ไปกด ⚙ ตั้งค่าเชื่อมต่อ

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บหลัก นำไปวางบน GitHub Pages ได้ทันที (มีข้อมูลฝังไว้ในตัวแล้ว) |
| `devices.csv` | ข้อมูลทั้งหมด 2,341 แถว สำหรับ import เข้า Google Sheet (มีคอลัมน์ VerifiedStatus/VerifiedDate ใหม่) |
| `feeders.csv` | ข้อมูลวงจรทั้ง 7 วงจร |
| `Code.gs` | Apps Script backend — รองรับแก้ไขข้อมูล + อัปโหลดรูปตรวจสอบภาคสนามขึ้น Drive |
| `comparison_report.xlsx` | รายงานเปรียบเทียบข้อมูล (จากรอบก่อน ยังใช้ได้) |
| `gis_transformers.csv`, `gis_mv_meters.csv`, `gis_mv_meter_accounts.csv` | ข้อมูลอ้างอิงหม้อแปลง/มิเตอร์ |

## คอลัมน์ใน devices.csv (อัปเดต)

`Feeder, DeviceID, Type, Rating, Description, Lat, Lon, Source, ParentID, MeterCount, VerifiedStatus, VerifiedDate`

- **Source** ค่าใหม่ที่เพิ่ม: `field-verified` = แก้ไขและยืนยันจากการตรวจภาคสนามจริง (น่าเชื่อถือที่สุด)
- **VerifiedStatus**: `match` (ตรงกับข้อมูลเดิม) / `mismatch` (แก้ไขแล้ว) / ว่าง = ยังไม่ตรวจ
- **VerifiedDate**: วันที่ตรวจสอบล่าสุด

## วิธี Deploy บน GitHub Pages

1. อัปโหลดไฟล์ `index.html` เข้า repo เดิม (ทับไฟล์เก่า) แล้ว Commit
2. รอ 1-2 นาที เปิดลิงก์เว็บไซต์เดิม (อาจต้อง Ctrl+F5 ล้างแคช)

## วิธีต่อกับ Google Sheet + Apps Script (จำเป็นสำหรับฟีเจอร์ตรวจสอบภาคสนาม)

1. สร้าง Google Sheet ใหม่ 1 ไฟล์
2. สร้างชีตชื่อ **Devices** แล้ว import ไฟล์ `devices.csv` (มี 12 คอลัมน์ตามด้านบน)
3. สร้างชีตชื่อ **Feeders** แล้ว import ไฟล์ `feeders.csv`
4. สร้างชีตชื่อ **FieldVerification** ใส่หัวตาราง: `Timestamp, Feeder, DeviceID, Status, CorrectedRating, CorrectedDesc, Note, PhotoUrl, Inspector`
   (ถ้าลืมสร้าง ระบบจะสร้างให้อัตโนมัติตอนบันทึกครั้งแรก)
5. เปิด Extensions > Apps Script วางโค้ดจากไฟล์ `Code.gs` ทับของเดิม
6. Deploy > New deployment > **Web app** (Execute as: Me, Who has access: Anyone)
7. คัดลอก URL (ลงท้าย `/exec`) → กดปุ่ม **⚙ ตั้งค่า** บนเว็บ → วาง URL → OK

หลังเชื่อมแล้ว รูปถ่ายจากการตรวจภาคสนามจะอัปโหลดเข้า Google Drive ของบัญชีที่ deploy Apps Script นี้
โดยอัตโนมัติ (โฟลเดอร์ชื่อ "SLD-อ่าวลึก-ภาพตรวจสอบภาคสนาม") — ครั้งแรกที่ใช้ Apps Script อาจขึ้นขอสิทธิ์
เข้าถึง Google Drive ให้กด "Allow" ได้เลย

## จุดที่ควรตรวจสอบเพิ่มเติม (ลำดับความสำคัญสำหรับงานภาคสนาม)

- อุปกรณ์ที่มีป้าย **"ประมาณ"** สีส้ม (206 ตัว) — ยังไม่มีค่าจากแบบมายืนยัน ควรตรวจสอบก่อนเป็นอันดับแรก
- อุปกรณ์ที่มีป้าย **"🔍ต้องตรวจสอบ"** — ยังไม่พบในฐานข้อมูล GIS เลย (ส่วนใหญ่คือคาปาซิเตอร์แบงค์)
- ใช้ปุ่ม **📊 รายงานเปรียบเทียบ** เพื่อดูสรุปจำนวนอุปกรณ์แต่ละกลุ่มและคลิกดูรายชื่อได้โดยตรง
